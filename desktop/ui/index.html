接入方式与限制

支持后台委派、进度查询和结果收集。a2a_stop 仅停止本地等待，不代表远端取消。当前运行记录由扩展管理，不是 Pi 原生独立子会话。

any-a2a 为不同 CLI 和 Agent 客户端提供统一的远端 A2A Agent 管理与接入。桌面端负责配置、部署和连接测试；客户端负责子 Agent 派发与结果回报，Rust CLI 负责 A2A 通信。具体支持范围见各客户端配置页。Agent Card 统一保存在本机应用数据目录。
